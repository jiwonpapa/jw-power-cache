# JW PowerCache v0.4.0-beta.1

공식 그누보드7 사용자·관리자 템플릿에 캐시 모드와 독립적으로 켜고 끌 수 있는 로딩 화면 개선 기능(Loading UX)을 추가했습니다.

## 주요 변경

- 전체 페이지 전환 스피너와 검토된 큰 콘텐츠 로딩 패턴 4개를 화면 구조에 맞는 스켈레톤으로 교체합니다.
- 저장·삭제·업로드·결제·모달 등 작업 진행 스피너는 변경하지 않습니다.
- 빠른 캐시 HIT에서 로딩 화면이 깜빡이지 않도록 스켈레톤 표시를 120ms 늦춥니다.
- 사용자·관리자·전체 적용 범위, 물결·맥박·애니메이션 없음, 반응형 화면, 다크 모드, 동작 줄이기, 접근성 상태를 지원합니다.
- 공개 병합 레이아웃 필터와 전환 오버레이 DOM·생명주기 계약을 사용하며, 코어 컴포넌트 레지스트리나 비공개 모듈을 가져오지 않습니다.
- 설정이나 플러그인 생명주기 상태가 바뀌면 병합 레이아웃·플러그인 번들 캐시만 무효화합니다.

## 호환성

- JW PowerCache: 공식 G7 7.0.9 이상, Page 1.1.0·Board 1.1.0·Ecommerce 1.2.0 이상
- 로딩 화면 전환 생명주기: G7 7.0.0~7.0.9 태그 소스에서 확인
- 공식 템플릿: `sirsoft-basic`, `sirsoft-admin_basic`
- 타사 템플릿: 별도 프로필을 추가하기 전까지 전환 오버레이 교체만 지원
