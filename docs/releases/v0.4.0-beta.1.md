# JW PowerCache v0.4.0-beta.1

This release adds an optional, cache-mode-independent Loading UX for official Gnuboard 7 user and administrator templates.

## Highlights

- Replaces full-page transition spinners and four audited large-content loading patterns with structure-aware skeletons.
- Keeps save, delete, upload, payment, modal, and other action spinners unchanged.
- Delays skeleton display by 120 ms so fast cache hits do not flash a loading surface.
- Supports user/admin/all scopes, wave/pulse/no animation, responsive layouts, dark mode, reduced motion, and accessibility status.
- Uses the public merged-layout filter and the stable transition-overlay DOM/lifecycle contract without importing a core component registry or private module.
- Invalidates only merged-layout and plugin bundle caches when Loading UX settings or plugin lifecycle state changes.

## Compatibility

- JW PowerCache: official G7 7.0.9 or later, Page 1.1.0, Board 1.1.0, Ecommerce 1.2.0 or later.
- Loading UX transition lifecycle: source-checked across G7 tags 7.0.0 through 7.0.9.
- Official templates: `sirsoft-basic` and `sirsoft-admin_basic`.
- Third-party templates: transition-overlay replacement only until an explicit profile is added.
