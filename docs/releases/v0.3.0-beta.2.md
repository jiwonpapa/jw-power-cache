# JW PowerCache v0.3.0-beta.2

This release restores stock Gnuboard compatibility and removes the private cache-store bypass.

## Highlights

- Supports official Gnuboard 7.0.9 and its bundled Page 1.1.0, Board 1.1.0, and Ecommerce 1.2.0 modules.
- Uses only the administrator-selected G7 cache store through the official `CacheInterface` and plugin cache namespace.
- Removes PowerCache-specific file/Redis stores, Redis connections, environment variables, and the cache-store selector.
- Uses expiring database lease rows for fill and control-plane locks, independent of the selected G7 cache driver.
- Treats the absence of an optional in-transaction hook seam as a documented doctor warning instead of blocking active mode.

## Compatibility note

Official G7 7.0.9 synchronous hooks are supported. Hooks emitted after an origin transaction commits retain a short process-crash window, so this beta does not claim fully atomic invalidation for every mutation path. Direct SQL and hook-bypassing importers still require an explicit scope or site purge.
