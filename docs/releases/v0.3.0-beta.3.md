# JW PowerCache v0.3.0-beta.3

일반 브라우저 세션과 로그인한 사용자에게도 공개 게시판 목록 캐시가 적용되도록 개선했습니다.

## 주요 변경

- 로그인한 사용자의 게시판 목록 응답을 사용자별 키로 저장합니다.
- 공개 요청·사용자 A·사용자 B의 키 공간을 분리해 `is_author`와 `abilities`가 사용자 사이에 섞이지 않게 합니다.
- 매 HIT 전에 원본과 같은 게시판 읽기 권한을 다시 검사합니다.
- 안전한 게시판 GET에는 G7 표준 세션·XSRF 정보를 허용하되, 공개 요청의 알 수 없는 쿠키와 민감 토큰은 계속 우회합니다.
- 브라우저에 남은 Bearer 인증정보를 `optional.sanctum`이 사용자로 해석하지 못한 경우에만 공개 요청으로 처리합니다. 인증된 사용자는 계속 ID별로 격리합니다.
- 인증된 페이지·쇼핑몰 카테고리 요청은 캐시하지 않습니다.

## 호환성 안내

미들웨어는 계속 `optional.sanctum` 이후, 경로 권한 미들웨어 이전에 실행됩니다. 인증된 사용자 정보를 캐시 키에 포함하고 HIT 반환 전에 같은 읽기 권한을 검사하려면 이 순서가 필요합니다.
