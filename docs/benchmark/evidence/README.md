# 벤치마크 원본 자료 안내

이 폴더의 JSON·텍스트 파일은 측정 도구와 서버에서 수집한 원본 결과입니다. 재현과 검증을 위해 필드 이름, 명령 출력, 수치, 시간, 체크섬은 번역하거나 수정하지 않습니다.

- `active`: 캐시 활성 모드
- `bypass`: 캐시를 사용하지 않고 원본으로 우회하는 모드
- `before` / `after`: 측정 전 / 후
- `telemetry`: CPU·메모리·DB·Redis 등 서버 자원 측정값
- `concurrency` / `VU`: 동시 요청 수 / 가상 사용자 수
- `RPS` / `requests/sec`: 초당 요청 수
- `p50` / `p95` / `p99`: 응답시간의 50·95·99백분위수
- `errors` / `evictions`: 오류 / 저장소에서 축출된 키

측정 방법과 해석은 [측정 방법](../methodology.md), [실서버 동시 사용자 5명 보고서](../g7devops-live-5vu-2026-09-01.md)를 참고하십시오. 원본 파일의 영어는 사용자 안내가 아닌 재현용 자료입니다.
