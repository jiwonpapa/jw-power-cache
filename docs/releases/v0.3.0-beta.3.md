# JW PowerCache v0.3.0-beta.3

This release makes the public board-list cache effective in normal browser sessions and for signed-in users.

## Highlights

- Caches signed-in board-list responses with a distinct key for each authenticated user.
- Keeps public, user A, and user B responses in separate key spaces so `is_author` and `abilities` never cross users.
- Rechecks the original board read permission before every HIT.
- Allows standard G7 session and XSRF context for safe board GET requests while unknown public cookies and sensitive tokens still bypass.
- Treats a Bearer credential left in the browser as public only when `optional.sanctum` resolves no user; authenticated users remain isolated by ID.
- Keeps authenticated page and ecommerce-category requests outside the cache.

## Compatibility note

The middleware still runs after `optional.sanctum` and before the route permission middleware. This is required so the authenticated identity can be included in the cache key while the plugin performs the same read-permission check before returning a HIT.
