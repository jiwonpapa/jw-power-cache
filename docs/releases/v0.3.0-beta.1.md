# JW PowerCache v0.3.0-beta.1

JW PowerCache의 첫 Open Source Beta입니다. 공개 JSON API만 보수적으로 캐시하며 인증·권한·개인화 응답은 항상 우회합니다.

## 주요 결과

- 원본 변경과 무효화 outbox를 동일 트랜잭션에 기록하고, 미적용 이벤트가 있으면 모든 HIT를 차단합니다.
- Redis 제어 키 유실·재시작·rollback·복구 후 과거 epoch 응답을 fail-closed 처리합니다.
- 관리자 설정, doctor, purge, reconcile, 백업 복구 finalize와 릴리스 rollback 절차를 제공합니다.
- 실제 MySQL·Redis 통합 테스트 51개/440 assertion과 PHP 8.2·8.5, MySQL 8.4, MariaDB 11.4 CI를 통과했습니다.
- 대표 공개 경로에서 BYPASS 대비 p95 28.8~42.4%, 처리량 43.5~69.0% 개선을 확인했습니다.
- 15분 장애 캠페인 7,203요청에서 오류·stale·개인화 응답 0건을 확인했습니다.

## 지원 경계

- G7: `jiwonpapa/gnuboard7` 커밋 `7d628dc4e57153a6217372a8a4bf8ea2904c680f`
- PHP: 8.2, 8.5
- 저장소: Redis 권장, file은 단일 노드만 지원
- 캐시 대상: 공개 페이지 상세, 공개 쇼핑몰 카테고리, 허용된 공개 게시판 목록

공식 G7 릴리스에 동일 트랜잭션 mutation 훅이 아직 포함되지 않았으므로 이 버전은 상용 Stable이 아닙니다. 다른 G7 커밋이나 이동 가능한 브랜치 HEAD는 지원 대상으로 간주하지 않습니다.

## 설치 전 필수 확인

1. DB와 플러그인 설정을 백업합니다.
2. 지원 G7 커밋을 정확히 고정합니다.
3. 플러그인을 설치한 뒤 `power-cache:doctor --json`이 오류 없이 통과하는지 확인합니다.
4. `bypass`에서 점검 후 `active`로 전환하고 오류율과 원본 응답 체크섬을 관찰합니다.

배포 ZIP과 `SHA256SUMS`는 이 릴리스 자산에서 제공하며 GitHub build provenance가 함께 발행됩니다. 세부 운영 절차와 제한은 README, SUPPORT, `docs/operations.md`를 따르십시오.
