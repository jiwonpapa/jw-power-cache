# JW PowerCache v0.3.0-beta.2

이 버전은 기본 그누보드와의 호환성을 복구하고, 플러그인 전용 캐시 저장소로 우회하던 구조를 제거했습니다.

## 주요 변경

- 공식 그누보드 7.0.9와 번들 모듈 Page 1.1.0·Board 1.1.0·Ecommerce 1.2.0을 지원합니다.
- 공식 `CacheInterface`와 플러그인 캐시 이름 공간을 통해 관리자가 선택한 G7 캐시 저장소만 사용합니다.
- PowerCache 전용 파일·Redis 저장소, Redis 연결, 환경변수, 저장소 선택 설정을 제거했습니다.
- 캐시 채우기와 제어 상태 잠금은 선택한 G7 캐시 드라이버와 무관하게 만료 시간이 있는 DB 임대 행을 사용합니다.
- 선택적인 트랜잭션 내부 훅이 없으면 활성 모드를 차단하는 대신 문서화된 진단 경고를 표시합니다.

## 호환성 안내

공식 G7 7.0.9의 동기 훅을 지원합니다. 원본 트랜잭션 커밋 후 실행되는 훅에는 프로세스가 비정상 종료될 수 있는 짧은 구간이 남으므로, 이 베타 버전은 모든 변경 경로의 완전한 원자적 무효화를 보장하지 않습니다. 직접 SQL을 실행하거나 가져오기 도구가 훅을 우회하면 영향 범위 또는 사이트 캐시를 명시적으로 무효화해야 합니다.
