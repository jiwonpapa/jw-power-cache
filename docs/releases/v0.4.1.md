# JW PowerCache v0.4.1

공식 G7 7.1.0의 방문자 통계 쿠키와 게시판 반응·회원 역할 일괄 변경을 지원하는 호환성 패치입니다. 최소 G7 버전은 `7.0.9`이며 기존 설정·캐시 저장소·Loading UX 동작을 유지합니다.

## 수정 사항

- 게시판 목록의 안전 GET에서 코어 설정 `analytics.cookies.visitor`·`analytics.cookies.opt_out`에 지정된 통계 쿠키만 허용합니다. G7 7.1.0 기본 이름은 `g7_vid`·`g7_analytics_optout`입니다. 이름을 바꾸면 설정된 이름만 허용하며, 해당 설정이 없는 G7 7.0.9에서는 기존 쿠키 정책이 유지됩니다.
- 미등록 쿠키는 계속 BYPASS하고 페이지·카테고리의 인증·쿠키 제외 정책은 유지합니다. 통계 쿠키를 삭제하거나 통계 수집·동의 설정을 바꾸지 않습니다.
- `sirsoft-board.reaction.after_react`에서 게시판 세대를 회전해 반응 추가·변경·해제 직후 목록 반응 수가 갱신됩니다.
- `core.user.after_bulk_update_roles`에서 게시판 세대를 회전해 캐시된 목록의 권한 표시를 갱신합니다. 읽기 권한은 계속 매 요청 검사하고 로그인 응답은 사용자 ID별로 격리합니다.
- 정책 키 `response-api-v5`가 기존 응답 키와 분리되므로 전체 캐시 삭제 없이 새 응답으로 전환합니다.

## 검증 범위

- 공식 G7 7.0.9: `56836a2b66c3bc4c3ae84ab1ae983248bb6d40b0`
- 공식 G7 7.1.0: `dbe88420c3219f42db1ac16a7e6bb17a438e144d`
- 통계 쿠키 값이 다른 요청의 동일 공개 HIT, 설정된 쿠키 이름 변경, 미등록 쿠키·페이지 쿠키 BYPASS
- 실제 G7 훅 등록기를 통한 반응 변경·역할 일괄 변경 직후 MISS 재생성 및 읽기 권한 회수 후 403 원본 경로
- 활성 guest 역할과 등록된 관리자 API 라우트를 갖춘 기존 PHP 테스트 환경
- CI의 PHP 8.2/8.5·두 공식 G7 버전과 G7 7.1.0의 MySQL 8.4/MariaDB 11.4·Redis 7.4

로컬에서는 두 공식 태그의 App 클래스로 고정한 소스와 설치된 G7 Laravel 라이브러리(PHP 8.5.3), 격리 SQLite·Redis 7.4를 사용해 각각 110개 테스트·653개 검증문을 통과했습니다. 코어에 없는 동일 트랜잭션 훅 검사 2개만 제외됐습니다. 프론트 테스트 23개와 타입검사도 통과했으며, 운영 서버에 패치를 설치한 결과를 의미하지는 않습니다.

## 배포 상태

이 문서는 `0.4.1` 소스와 검증 계약을 기록합니다. 브랜치 푸시만으로는 G7 업데이트 확인의 GitHub Latest 릴리스에 표시되지 않습니다. ZIP 릴리스 발행과 운영 서버 업데이트는 별도 절차이며, 이 패치에 새 DB 마이그레이션은 없습니다.

표준 G7의 커밋과 after 훅 발행 사이 비정상 종료 구간은 기존과 같으며, 이 패치가 원자적 정합성 보증을 추가하지는 않습니다.
